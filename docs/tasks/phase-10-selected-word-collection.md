# Phase 10 — Явное добавление слов после уроков

## Решение

В Lingo IQ слово никогда не добавляется в личные флешкарты молча. Пользователь
явно выбирает слова чекбоксами в финальном шаге учебного потока.

Источники личных слов:

- `lesson` — выбор после завершения урока;
- `bank` — выбор после завершения учебного потока Банка слов;
- `manual` — ручной ввод пользователем.

Удалены из продукта как источники добавления:

- автоматическое добавление после правильного ответа;
- добавление после завершения всего трека;
- AI-рекомендации флешкарт.

## Потоки

### Урок

Первые 15 шагов работают как обычные учебные шаги. После завершения последнего
шага приложение показывает логический шаг `16` — экран выбора слов:

```text
Урок завершён → выбрать слова → добавить выбранные в «Мои слова»
```

Список строится по уникальным `vocabulary_id`, встреченным в содержимом урока.
Добавление идемпотентно: повторный выбор уже существующего слова не создаёт
дубликат.

### Банк слов

После завершения учебных активностей слова Банка слов предлагаются в таком же
экране выбора. Источник создаваемой карточки — `bank`.

### Ручной ввод

`POST /flashcards` создаёт карточку без `vocabulary_id` с источником `manual`.
Поля слова и перевода обязательны; определение и пример опциональны.

## Данные

`courses.vocabulary` остаётся каноническим системным словарём. Трек связан со
словами через `track_vocabulary`, но трек сам по себе не создаёт личных слов.
Личная карточка хранит `vocabulary_id` для слов урока/банка и уникальна по
`(user_id, vocabulary_id)`. Ручные карточки могут не иметь `vocabulary_id`.

SRS создаётся только после явного добавления слова. В сегодняшнюю сессию новые
слова попадают через дневной лимит, а не все сразу.

## API

Для выбора системных слов используется идемпотентный bulk endpoint:

```http
POST /api/v1/flashcards/bulk
```

Каждый item содержит `vocabulary_id`, `word`, `translation` и `source` (`lesson`
или `bank`). Дубликаты возвращаются как `skipped`.

## Масштабирование

- каталог и личная библиотека загружаются страницами;
- экран выбора ограничивает количество отправляемых элементов и использует
  серверную дедупликацию;
- SRS выбирает небольшую дневную очередь, а не весь словарь пользователя;
- треки остаются контекстом происхождения слов, но не являются отдельным
  способом добавления.

## Acceptance criteria

- после 15-го шага урока появляется финальный экран выбора слов;
- пользователь может выбрать все или отдельные слова;
- повторное добавление не создаёт дубль;
- после Банка слов работает тот же сценарий с источником `bank`;
- ручное слово добавляется без системного `vocabulary_id`;
- авто-add из `step-validation-service` не вызывается;
- AI-блок рекомендаций отсутствует в мобильном UI и gateway-маршрутах;
- прямое добавление слов на уровне трека отсутствует в мобильном UI;
- backend и mobile тесты покрывают выбор, пропуск и дедупликацию.
