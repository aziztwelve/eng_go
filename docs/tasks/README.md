# 🎯 Roadmap: От базовой LMS к Duolingo-like платформе

Этот раздел содержит детальный план развития платформы на 6 фаз. Платформа развивается от текущего состояния (базовая LMS с курсами/уроками/прогрессом) к полноценному конкуренту Duolingo с фокусом на изучение языков.

## 🎯 Целевое состояние (vision)

Платформа изучения языков с:
- 🎮 Геймификацией как у Duolingo (XP, streaks, hearts, leagues)
- 🧠 Адаптивным обучением (spaced repetition)
- 🎯 Разнообразными форматами упражнений
- 🤖 AI-учителем для разговоров и объяснений
- 💰 Подпиской + покупкой курсов (гибридная монетизация)
- 📱 Кросс-платформенностью (web + mobile)

**Бизнес-направление:** изучение языков (английский, испанский, немецкий, казахский и т.д.)

## 🏛️ Принцип: две независимые структуры контента

Платформа поддерживает **ДВА параллельных способа создания обучающего контента**:

### 1. 📚 Курсы (Courses) — структурированные пакеты
Существующая модель: `Course → Module → Lesson → Step`

**Когда использовать:**
- Целостная программа обучения (например, "Английский с нуля до B2")
- Премиум-контент, продаваемый как продукт (IELTS, TOEFL, Business English)
- Курсы от преподавателей/инфлюенсеров

**Особенности:**
- Имеет автора (instructor)
- Может быть платным (purchase) или бесплатным
- Прогресс отслеживается на уровне курса
- Сертификат после завершения

### 2. 🎯 Standalone-контент (Independent Lessons)
**НОВАЯ структура** — отдельные уроки и шаги БЕЗ привязки к курсу.

**Когда использовать:**
- Ежедневная практика (Daily Lesson)
- Тематические подборки (Stories, Podcasts, Quick Tips)
- Свободное изучение по интересам
- Контент, который не вписывается в курс

**Особенности:**
- Не требует записи на курс
- Доступен сразу всем пользователям (или по тегам/темам)
- Можно группировать в **Learning Tracks** (треки) — лёгкие ассоциации без жёсткой иерархии
- Прогресс — на уровне уроков/шагов

### 🎮 Геймификация работает в обеих структурах одинаково

**Принцип:** XP, streaks, hearts, leagues, achievements — это **отдельная подсистема**, которая привязана к **действиям пользователя** (выполнение шага), а НЕ к контейнеру (курсу/треку).

```
Пользователь выполнил Step
    ↓
gamification.AddXP() ← вызывается одинаково
    ↓
[не важно: был ли Step в Course, в Track, или сам по себе]
```

Подробности: [phase-0-standalone-content.md](./phase-0-standalone-content.md)

## 📋 Phase 1: Геймификация 🎮

**Цель:** Превратить обучение в игру — добавить мотивацию через систему XP, streaks и hearts.

### Главные фичи:
- ⚡ **XP система** — очки опыта за каждый шаг
- 🔥 **Streaks** — полоса дней подряд (главный мотиватор Duolingo)
- ❤️ **Hearts/Lives** — 5 жизней, тратятся за ошибки, восстанавливаются со временем
- 🎯 **Daily Goals** — ежедневная цель (10/20/30/50 XP)
- 🏆 **Achievements/Badges** — 30+ достижений
- 📊 **User Level** — уровень пользователя (1-100)
- 💎 **Gems** — внутренняя валюта (для покупки streak freeze и т.д.)

**Подробно:** [phase-1-gamification.md](./phase-1-gamification.md)

---

## 📋 Phase 2: Новые форматы шагов 🎯

**Цель:** Добавить разнообразные интерактивные упражнения вместо одних текстов и квизов.

### Главные фичи:
- 🌐 **Translate** — drag&drop сборка перевода предложения
- 🔗 **Match Pairs** — сопоставление слово ↔ перевод
- 🎧 **Listening** — слушай аудио и пиши что слышишь (TTS)
- ✍️ **Fill in the Blank** — вставь пропущенное слово
- 📖 **Stories** (бонус) — интерактивные диалоги

**Подробно:** [phase-2-step-formats.md](./phase-2-step-formats.md)

---

## 📋 Phase 3: Адаптивное обучение 🧠

**Цель:** Умное повторение материала по алгоритму spaced repetition (как Anki).

### Главные фичи:
- 🔁 **Spaced Repetition (SM-2)** — алгоритм интервального повторения
- ❌ **Mistakes Review** — работа над ошибками
- 🎯 **Practice Hub** — раздел повторения
- 📉 **Skill Decay** — "ржавчина" навыков (надо повторять)
- 📊 **Personal Stats** — слабые/сильные темы

**Подробно:** [phase-3-adaptive-learning.md](./phase-3-adaptive-learning.md)

---

## 📋 Phase 4: Социальное (Leagues) 🏆

**Цель:** Соревновательность через лиги и друзей.

### Главные фичи:
- 🏅 **Leagues** — 10 лиг (Bronze → Silver → Gold → ... → Diamond)
- 📊 **Weekly Leaderboards** — 30 человек на лигу, недельный сброс
- ⬆️ **Promotion zone** — топ-7 повышаются
- ⬇️ **Demotion zone** — низ-5 понижаются
- 👥 **Friends** — добавление друзей, активность
- 🌍 **Global Leaderboard** — топ всех пользователей

**Подробно:** [phase-4-social.md](./phase-4-social.md)

## 📋 Phase 5: AI интеграция 🤖

**Цель:** Уникальный фичур для выделения от конкурентов — полноценный AI учитель.

### Главные фичи:
- 💬 **AI Conversation** — разговорная практика с AI
- 🎭 **Roleplay** — ролевые сценарии (ресторан, аэропорт)
- 🤔 **Explain My Answer** — AI объясняет ошибки
- ✍️ **AI Writing Assessment** — проверка письменных текстов
- 🎤 **Pronunciation Check** — AI оценивает произношение
- 🎓 **AI Tutor** — персональный учитель

**Технологии:** OpenAI GPT-4 / Claude, Whisper, Web Speech API

**Подробно:** [phase-5-ai-integration.md](./phase-5-ai-integration.md)

## 📋 Phase 6: Монетизация 💰

**Цель:** Запуск гибридной модели — подписка + покупка курсов.

### Главные фичи:
- 💎 **Premium Subscription** ($7-9/мес):
  - ♾️ Неограниченные hearts
  - 🚫 Без рекламы
  - 🤖 Полный AI доступ
  - 🎯 Streak freeze (2/мес)
- 🛒 **Course Purchases** ($19-49):
  - Премиум курсы от носителей
  - IELTS/TOEFL подготовка
- 🆓 **Free tier**:
  - 5 hearts (восстанавливаются)
  - Реклама
  - Базовый AI (5 запросов/день)

**Интеграции:** Stripe, Kaspi Pay (для Казахстана)

**Подробно:** [phase-6-monetization.md](./phase-6-monetization.md)

## 🎯 Принципы реализации

### Архитектурные:
1. **Микросервисная архитектура** — каждая фаза вводит свой сервис или расширяет существующий
2. **gRPC между сервисами** — синхронная коммуникация
3. **Kafka для событий** — асинхронные события (achievement unlocked, league reset)
4. **PostgreSQL** — основное хранилище
5. **Redis** — кэш и leaderboards (sorted sets)

### Кодовые:
1. **Clean Architecture** — model → repository → service → api
2. **TypeScript strict** на фронте
3. **Тесты** — unit для бизнес-логики, integration для API
4. **Миграции** — все изменения схемы через миграции
5. **API versioning** — `/api/v1/` префикс

### UX:
1. **Mobile-first** — основной фокус на мобильное приложение
2. **Web как поддержка** — Next.js для админки и веб-версии
3. **Анимации** — Framer Motion / Lottie для мотивации
4. **Звуки** — feedback на правильно/неправильно
5. **Темная тема** — обязательна

## 🚀 С чего начать?

**Рекомендация:** Начать с **Phase 1 (Геймификация)**, потому что:
- ✅ Базовый бэкенд уже готов
- ✅ Сразу повысит engagement пользователей
- ✅ Не блокирует другие фазы
- ✅ Можно тестировать на реальных пользователях быстро

**Затем:** Phase 2 (новые форматы) — даст контентное разнообразие.

**Параллельно:** Phase 4 (Leagues) можно делать вместе с Phase 1, т.к. они оба используют XP.
