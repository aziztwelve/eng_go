# Profile reliability release — 2026-10-24

Additive `GET/PATCH /api/v1/users/me/profile` endpoints use only the authenticated user ID. Name, birthday, time zone and optional gender are persisted; invalid values return 400. Apply `services/user-service/migrations/008_profile_gender.sql` before starting the new user-service. It adds one nullable column and preserves existing clients/data.

`GET /api/v1/gamification/xp/daily?days=14` returns all daily XP totals in the account time zone, independent of history pagination. Existing XP history request/response fields remain unchanged; protobuf fields are additive. Streak history adds `today` and `timezone` for calendar alignment.

Legacy freeze activation is idempotent and no longer grants free freezes. Existing reserves are applied automatically by the existing streak progression logic.

Validation: build all 12 services; tests user-service, gamification-service and gateway; public disposable-account smoke `python3 scripts/smoke-profile.py --base-url https://api.lingoiq.online/api/v1`. The smoke deletes only accounts it creates.

Deployment: the existing server checkout contains unrelated untracked track content. Preserve it. Build this release in an isolated detached checkout and install only the changed auth-service, user-service, gamification-service and gateway binaries, retaining previous binaries for rollback. Other services and the existing checkout remain in place.

Access-token validation now rejects deleted accounts immediately and uses the current account role/guest state. Authentication database outages are propagated as Unavailable (HTTP 503), never as revoked sessions. Auth tests cover both paths.
