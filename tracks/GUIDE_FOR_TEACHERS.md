# 📚 Руководство для преподавателя по созданию треков

**Дата:** 2026-06-03  
**Версия:** 1.0

---

## 🎯 Обзор

Вам необходимо заполнить **1,500 треков** для обучения английскому языку.

### Структура:
- **5 уровней**: A1, A2, B1, B2, C1
- **6 целей**: work, travel, education, hobby, family, career
- **50 треков** на каждую комбинацию уровень + цель

### Где находятся файлы:
```
tracks/
├── a1-work/          (50 файлов: a1-work-001.json ... a1-work-050.json)
├── a1-travel/        (50 файлов)
├── a1-education/     (50 файлов)
├── ...
└── c1-career/        (50 файлов)
```

---

## 📝 Как заполнять треки

### Шаг 1: Откройте файл
Откройте любой `.json` файл в текстовом редакторе (VS Code, Sublime, даже Notepad).

Пример: `tracks/a1-work/a1-work-001.json`

### Шаг 2: Следуйте инструкциям
В каждом файле есть:
- `_instructions` - что нужно сделать
- `_theme_suggestion` - предложенная тема
- `[ЗАПОЛНИТЕ]` - места для заполнения
- `[ВЫБЕРИТЕ]` - варианты выбора

### Шаг 3: Заполните track_info

```json
"track_info": {
  "code": "a1-work-001",  // НЕ ТРОГАТЬ
  "title": "Офисные приветствия",  // ✏️ ЗАПОЛНИТЬ
  "description": "Научитесь здороваться с коллегами",  // ✏️ ЗАПОЛНИТЬ
  "language": "en",  // НЕ ТРОГАТЬ
  "level": "A1",  // НЕ ТРОГАТЬ
  "goal": "work",  // НЕ ТРОГАТЬ
  "track_type": "thematic",  // НЕ ТРОГАТЬ
  "difficulty": 1,  // НЕ ТРОГАТЬ
  "estimated_duration_minutes": 25,  // ✏️ ЗАПОЛНИТЬ (20-60)
  "icon_url": "https://example.com/icon.png",  // ✏️ ЗАПОЛНИТЬ (опционально)
  "tags": ["greetings", "office", "conversation"]  // ✏️ ЗАПОЛНИТЬ (3-5 тегов)
}
```

### Шаг 4: Создайте уроки

Каждый трек должен содержать **5-10 уроков**.

```json
"lessons": [
  {
    "title": "Урок 1: Базовые приветствия",
    "description": "Изучите основные способы поздороваться",
    "order_index": 1,
    "estimated_duration_minutes": 5,
    "steps": [...]
  },
  {
    "title": "Урок 2: Представление себя",
    "order_index": 2,
    ...
  }
]
```

### Шаг 5: Добавьте шаги

Каждый урок должен содержать **5-8 шагов**.

#### Типы шагов:

1. **video** - видео урок
2. **text** - текстовый материал
3. **translate** - перевод предложений
4. **fill_blank** - заполнить пропуски
5. **match_pairs** - сопоставить пары
6. **listening** - аудирование
7. **quiz** - тест
8. **story** - история с картинками
9. **tap_words** - собрать предложение из слов
10. **ai_writing** - письменное задание

#### Пример шага - video:

```json
{
  "order_index": 1,
  "type": "video",
  "title": "Смотрите: Приветствия в офисе",
  "content": {
    "video_id": "uuid-from-system",
    "duration_seconds": 120,
    "transcript": "Hello everyone! Today we'll learn..."
  }
}
```

#### Пример шага - match_pairs:

```json
{
  "order_index": 2,
  "type": "match_pairs",
  "title": "Сопоставьте приветствия",
  "content": {
    "pairs": [
      {"left": "Good morning", "right": "Доброе утро"},
      {"left": "Hello", "right": "Здравствуйте"},
      {"left": "Hi", "right": "Привет"}
    ]
  }
}
```

#### Пример шага - fill_blank:

```json
{
  "order_index": 3,
  "type": "fill_blank",
  "title": "Заполните пропуски",
  "content": {
    "text": "Good ___, Sarah! How ___ you today?",
    "blanks": [
      {
        "position": 5,
        "correct_answers": ["morning"],
        "hint": "время суток"
      },
      {
        "position": 23,
        "correct_answers": ["are"],
        "hint": "глагол to be"
      }
    ]
  }
}
```

## 🎓 Рекомендации по содержанию

### По уровням:

#### A1 (Beginner)
- Словарный запас: 5-10 новых слов на урок
- Длина предложений: 5-8 слов
- Грамматика: present simple, pronouns, базовые вопросы
- Темы: приветствия, семья, работа, еда, дом

#### A2 (Elementary)
- Словарный запас: 10-15 новых слов
- Длина предложений: 8-12 слов
- Грамматика: past simple, present continuous, сравнения
- Темы: путешествия, хобби, покупки, здоровье

#### B1 (Intermediate)
- Словарный запас: 15-20 новых слов
- Длина предложений: 12-15 слов
- Грамматика: условные предложения, пассивный залог, present perfect
- Темы: работа, образование, технологии, культура

#### B2 (Upper-Intermediate)
- Словарный запас: 20-25 новых слов
- Длина предложений: 15-20 слов
- Грамматика: сложные времена, косвенная речь, модальные глаголы
- Темы: карьера, общество, наука, искусство

#### C1 (Advanced)
- Словарный запас: 25-30 новых слов
- Длина предложений: 20+ слов
- Грамматика: все аспекты, идиомы, фразовые глаголы
- Темы: профессиональные, академические, абстрактные

### По целям:

#### work (Работа)
- Лексика: meeting, deadline, colleague, presentation, report
- Сценарии: совещания, email, телефонные звонки, переговоры
- Стиль: формальный

#### travel (Путешествия)
- Лексика: airport, hotel, restaurant, ticket, directions
- Сценарии: бронирование, заказ еды, просьба о помощи
- Стиль: практический, survival English

#### education (Образование)
- Лексика: lecture, assignment, research, exam, essay
- Сценарии: классная комната, библиотека, дискуссии
- Стиль: академический

#### hobby (Хобби)
- Лексика: leisure, entertainment, interests, passion
- Сценарии: спорт, музыка, искусство, кулинария
- Стиль: неформальный, разговорный

#### family (Семья)
- Лексика: relatives, home, routine, celebrations
- Сценарии: разговоры, традиции, быт
- Стиль: личный, эмоциональный

#### career (Карьера)
- Лексика: interview, CV, skills, promotion, networking
- Сценарии: поиск работы, собеседования, развитие
- Стиль: профессиональный, мотивационный

## 🏗️ Структура урока (рекомендуется)

### 1. Warm-up (1-2 шага)
- **video** или **text**
- Введение в тему
- Мотивация

### 2. Presentation (1-2 шага)
- **text** с примерами
- Объяснение грамматики/лексики

### 3. Practice (3-5 шагов)
- **translate**
- **fill_blank**
- **match_pairs**
- **tap_words**
- Интерактивная практика

### 4. Production (1-2 шага)
- **quiz** (проверка понимания)
- **ai_writing** (свободное применение)

### 5. Cool-down (1 шаг)
- **story** или **listening**
- Закрепление в контексте

## 💾 После заполнения

### Импорт в систему:

```bash
# Один трек
python3 scripts/import_tracks_from_json.py tracks/a1-work/a1-work-001.json

# Все треки для A1-work
python3 scripts/import_tracks_from_json.py tracks/a1-work/*.json

# Все треки одного уровня
python3 scripts/import_tracks_from_json.py tracks/a1-*/*.json

# Все треки (осторожно!)
find tracks -name "*.json" | xargs python3 scripts/import_tracks_from_json.py
```
